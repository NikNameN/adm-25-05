# АДМ-25-05

Чтобы сайт открывался на iPhone как страница, а не как код:

1. Открой [Settings → Pages](https://github.com/NikNameN/adm-25-05/settings/pages)
2. Source: Deploy from a branch
3. Branch: `main` / folder: `/ (root)` → Save
4. Через минуту открой в Safari:
   https://niknamen.github.io/adm-25-05/
5. Поделиться → На экран «Домой»
